# BRASA. — Monte o teu Smash

Projeto visual da experiência interativa BRASA.

A versão publicada está em https://brasa-burger-experience.vercel.app/.

A implementação de melhoria visual de 12/11/2026 preserva a versão original disponibilizada no deployment da Vercel e acrescenta efeitos de iluminação, animação nos botões e a secção de acompanhamentos.

**Nota técnica:** O ficheiro `original.html` e os seus recursos continuam guardados no deployment original da Vercel. O repositório documenta os novos ficheiros de interface, mas ainda não constitui um espelho completo de todos os assets da produção.
